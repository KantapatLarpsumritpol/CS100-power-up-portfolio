# CS100 Power Up Portfolio

A portfolio website made with HTML, CSS, JavaScript and Bootstrap. You can create portfolios and add items to them, and each item shows up as a card.

## How to Open

1. Download or clone this repository.
2. Open `index.html` in a browser.
3.You need internet because Bootstrap is loaded from a CDN.


## How to Test

### Step 1: Create a portfolio
1. On the Home page, click **Create New Portfolio**.
2. Fill in Display Name, What I Enjoy, What I've Tried, and What I'm Curious About.
3. Click **Save & Create Portfolio**. A portfolio card appears on Home, and a link is added to the navbar.

### Step 2: Open the portfolio
1. Click the portfolio card (or its link in the navbar).
2. The profile and its items are shown. Click **Home** to go back.

### Step 3: Add an item
1. Click **+ add item**.
2. Fill in every field (Title, Type, Date, Role, Skills, Description, Reflection, Evidence link). Separate skills with commas.
3. Click **Submit Item**. The item appears as a card.

### Step 4: Test validation
1. Leave any field empty and submit. An error message appears.
2. Enter an invalid Evidence link (it must start with `http://` or `https://`) and submit. An error message appears.

### Step 5: Test saving
1. Refresh the page.
2. The portfolios and items should still be there.
